# Healthy Kitchen

A mobile-first Progressive Web App for managing healthy groceries, food,
fruits, vegetables, protein, snacks and kitchen supplies.

## Features

- Grocery categories
- Search
- Status tracking
- Needed
- Bought
- Low stock
- Out of stock
- Shopping mode
- Add custom items
- Edit items
- Delete items
- Quantity
- Notes
- Shopping progress
- Offline support
- Local device storage
- Installable as a mobile app
- GitHub Pages compatible

## GitHub Pages Setup

1. Create a new GitHub repository.

Example:

healthy-kitchen

2. Upload all project files.

3. Open:

Repository
→ Settings
→ Pages

4. Under Build and deployment select:

Source:
Deploy from a branch

Branch:
main

Folder:
/

5. Click Save.

GitHub will provide a URL similar to:

https://YOUR-USERNAME.github.io/healthy-kitchen/

## Android Installation

Open the GitHub Pages URL in Chrome.

Select:

Menu
→ Add to Home screen

or:

Install app

The app will then appear on your Android home screen.

## iPhone Installation

Open the GitHub Pages URL in Safari.

Tap:

Share
→ Add to Home Screen

The app will then appear on your iPhone home screen.

## Data

The application stores the grocery list in localStorage.

No account is required.

No external database is required.

Data is stored separately on each device.

## Important

If you clear the browser's site data, your local grocery list may be deleted.

If you want the same grocery list synchronized across multiple phones,
a cloud database can be added later.
